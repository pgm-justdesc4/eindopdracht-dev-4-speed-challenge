# Get Started: Speed Challenge System

Follow these steps to set up the environment and run the Speed Challenge application on your Raspberry Pi.

## 1. Environment Setup

1. Create the virtual environment (if not already done):
    ```bash
    python3 -m venv venv
    ```

2. Activate the environment:
    ```bash
    source venv/bin/activate
    ```

3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

<br />

## 2. Running the Application

Once the environment is active and hardware is connected, launch the main script:

```bash
  python3 main.py
```
