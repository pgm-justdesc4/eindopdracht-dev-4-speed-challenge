# Speed Challenge

An IoT installation combining running, competition and athletics trivia. Users race between two pillars, receive their time and a fun fact and compete for the high score. A printed ticket provides a physical reminder of their result.

# Tech Stack

## Software
- C++ (.ino)
- Python
- Socket.io

## Hardware
- Raspberry Pi
- ESP32 C3 (2x)
- Arcade buttons (2x)
- Timer
- Ticketprinter
- LCD screen
- Piezo speaker
